# Notebooks

Interactive walkthroughs of the Repère framework. Each notebook is
self-contained and re-runs cleanly from a fresh kernel.

| File | What it shows |
| --- | --- |
| [`01_skill_lift_quickstart.ipynb`](01_skill_lift_quickstart.ipynb) | Three small models (mistral:7b, llama3.1:8b, qwen2.5:7b) running the public STA/LTA intent-extraction suite under `none` vs `full` skill conditions, with per-model skill-lift output. |
| [`02_stalta_golden_explorer.ipynb`](02_stalta_golden_explorer.ipynb) | Interactive golden-dataset builder: fetch waveforms from FDSN for every event in `events.yaml`, plot waveform + STA/LTA characteristic function, tune parameters, and export per-event YAML annotations to `goldens/annotations/`. |
| [`03_react_baseline.ipynb`](03_react_baseline.ipynb) | The ReAct multi-step agent baseline (P2.4): three Inspect tools (`fdsn_get_waveforms`, `python_session`, `record_submit`), the `stalta_react` solver wrapping Inspect's `basic_agent`, a free `mockllm/model` dry-run, and the one-line swap to a live provider (`anthropic/claude-haiku-4-5-...`). Needs the optional `[eval]` extra. |

## Launching

From the repo root:

```bash
pip install -e ".[dev]"
pip install jupyter
jupyter lab notebooks/
```

If you use Pixi:

```bash
pixi install
pixi run pip install jupyter
pixi run jupyter lab notebooks/
```

## Notes

- The default path uses `EchoAdapter` to simulate the three models so the
  notebook runs offline and deterministically. CI uses the same code path.
- The last section of the quickstart shows how to swap to a live Ollama
  server with a one-line factory change (uncomment the cell, re-run).
- The notebooks are generated by sibling builder scripts. To regenerate
  after edits to a builder, run:

  ```bash
  python notebooks/_build_notebook.py          # 01_skill_lift_quickstart.ipynb
  python notebooks/_build_react_baseline.py    # 03_react_baseline.ipynb
  ```
